## v1.1 候选功能清单

> 以下功能按优先级排序，请用户勾选哪些做、哪些不做。

### 高优先级（用户体验提升明显）

#### 1. 一闪念（短想法/碎片记录）
- **说明：** 短粒度内容流，比博客更轻量，随手记录想法、灵感、碎碎念
- **数据结构：** 独立 collection，比博客少一些字段（不需要 tags/category/summary）
- **页面：** `/notes` 列表页 + 详情页（可选，一闪念不需要详情页，直接展开）
- **PRD 来源：** v1.0 PRD 里推迟到 v1.5 的功能
- **工作量：** 中
- **是否做：** ☐

#### 2. 博客相关文章推荐
- **说明：** 博客详情页底部，推荐同标签的其他文章
- **数据来源：** 按 tags 交集排序，取前 3 篇
- **PRD 来源：** 项目详情页已经做了相关推荐，博客也应该有
- **工作量：** 低
- **是否做：** ☐

#### 3. 博客分享按钮
- **说明：** 博客文章底部加分享按钮（复制链接/分享到微博/分享到 X）
- **实现：** 纯前端，调用浏览器分享 API + 复制链接
- **工作量：** 低
- **是否做：** ☐

#### 4. 页脚 RSS 订阅按钮
- **说明：** 页脚加一个 RSS 图标链接，方便用户订阅
- **工作量：** 极低
- **是否做：** ☐

### 中优先级（功能增强）

#### 5. 收藏夹统计页
- **说明：** `/collections/stats` 页面，显示：
  - 今年读了多少本书/看了多少部电影/听了多少首歌
  - 平均评分
  - 最高评分的几条
  - 年度报告风的可视化（简单的数字卡片）
- **PRD 来源：** v1.0 PRD 里提到的 v1.5 功能
- **工作量：** 中
- **是否做：** ☐

#### 6. 博客标签云
- **说明：** 标签页改成云样式，按文章数量调整字号
- **工作量：** 低
- **是否做：** ☐

#### 7. 图片优化（astro:assets）
- **说明：** 博客/项目里的图片走 astro:assets 自动压缩 + WebP/AVIF + 响应式
- **PRD 来源：** v1.0 PRD 里提到的性能优化项
- **工作量：** 中（需要改现有内容的图片引用方式）
- **是否做：** ☐

#### 8. OG 图片自动生成
- **说明：** 每篇博客自动生成 OG 分享图（标题 + 头像 + 渐变背景）
- **实现：** 用 astro og 图片生成组件
- **工作量：** 中
- **是否做：** ☐

- **工作量：** 极低
