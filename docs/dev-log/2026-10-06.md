### ISSUE-015：导航切换页面后，主题切换按钮失效
- **现象**：第一次进入网站后（整页加载时主题切换正常），切换导航页面后，再点主题切换无任何反应。
- **排查**：bu 平面复现——整页加载首页点击主题正常（class 变化 + localStorage 写入）；ClientRouter 导航到 /projects 后点主题，class 与 localStorage 均无变化，console 无报错。
- **根因**：Astro `<ClientRouter />`（View Transitions）导航时旧 DOM 被替换成新页 DOM，而 Header.astro 的 `<script>` 在 swap 前执行、监听器绑在旧节点上 → 新页面的主题按钮没有任何事件监听器。
- **修复**（`src/components/Header.astro` + `src/layouts/BaseLayout.astro`）：
  - 全部改为 `bindHeader() / bindCommon()` 函数 + `document.addEventListener('astro:page-load', bindX)`——每次导航后新 DOM 就绪时重新绑定；
  - 按钮级用 `dataset.bound` 防重复绑定；document/window 级监听器（菜单外点击关闭、resize、进度条点击捕获、进度条导航完成、/ 快捷键）用 `window.__xxxBound` 全局标记只注册一次。
- **验证**：本地（localhost）导航→点主题→切 dark 成功；线上（philia093.ink）整页加载 light→dark 成功、导航到 /projects 后 dark→light 成功（`bound=1 out=true prog=true` 确认修复代码已上线）。

### ISSUE-016：CMS 后台发布内容，后台显示但前台不显示
- **现象**：用户通过 /manage 发布测试博客（标题"网站后台测试"），后台列表能看到，前台博客列表/首页均不显示。
- **排查**：远程仓库有用户 CMS 测试提交（`13e4e27`/`79c254c`），文件 frontmatter 为 `draft: false; visible: false`；而 zod schema blog 默认 `visible: true`（schema 默认公开，前台过滤掉 visible:false）。
- **根因**：`public/manage/app.js` 新建表单 boolean 字段初始化 `cb.checked = !!initial[f.key]`——新建时 initial 为空，所有 checkbox 默认 false → 保存时写入 `visible: false`，与 schema 默认相反，被前台过滤。
- **修复**：
  - `public/manage/collections.js`：给全部 boolean 字段加 `default`（blog `visible` 默认 `true`、所有 `draft` 默认 `false`、projects `featured` 默认 `false`、books `reread` 默认 `false`）；
  - `public/manage/app.js`：boolean 初始化改为 `cb.checked = initial[f.key] !== undefined ? !!initial[f.key] : !!f.default`；
  - 用户已发布的测试博客 `src/content/blog/2026-10-06-untitled.md` 改为 `visible: true`。
- **验证**：本地 wrangler 新建博客 → "公开" checkbox 默认勾选、"草稿"默认不勾选；线上 /blog 列表出现"网站后台测试"、详情页 `/blog/2026-10-06-untitled` 200 可访问。
- **备注**：测试博客现为公开，若用户不想要可在 /manage 删除。
